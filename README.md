# DJ Diplomata · Site

Site oficial do artista (Progressive, Trance e PsyTrance · Curitiba). Stack: HTML, CSS e JavaScript estáticos, deploy no Netlify.

## Início rápido

```bash
npx serve .
```

Abra `http://localhost:3000/` (ou use Live Server na porta configurada em `.vscode/settings.json`).

## Onde editar

- **Textos e seções da home:** `index.html`
- **Canais (e-mail, redes, domínio):** `js/config.js`
- **Estilo global:** `css/styles.css`
- **Outras páginas:** `paginas/`

## Documentação

Mapa completo de pastas, URLs e deploy: **[docs/ESTRUTURA.md](docs/ESTRUTURA.md)**.
